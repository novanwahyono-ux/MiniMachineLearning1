# Graph Search Algorithms (Python)

A collection of graph traversal and search algorithm implementations using Python and Jupyter Notebook.

This repository explores fundamental AI and graph search techniques including BFS, DFS, Uniform Cost Search, Depth Limited Search, and Iterative Deepening DFS.

---

# Topics Covered

- Breadth First Search (BFS)
- Depth First Search (DFS)
- Depth Limited Search (DLS)
- Iterative Deepening DFS (IDDFS)
- Uniform Cost Search (UCS)
- Graph traversal
- Pathfinding concepts
- Weighted graph search

- Jupyter Notebook
