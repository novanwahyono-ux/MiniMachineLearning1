# AI Search Algorithms

This project demonstrates the implementation of several informed search algorithms in Python, including:

* Greedy Best First Search
* A* (A-Star) Search Algorithm
* Maze Pathfinding
* Romania Route Search Problem

The project focuses on artificial intelligence search techniques and heuristic-based pathfinding.

---

## Features

* Maze solving visualization
* Heuristic-based search
* Pathfinding simulation
* Romania map shortest path problem
* Python implementation of AI search algorithms

---

## Algorithms Used

### Greedy Best First Search

Uses heuristic values to select the node that appears closest to the goal.

### A* Search Algorithm

Combines:

* actual path cost `g(n)`
* heuristic estimate `h(n)`

to calculate:

`f(n) = g(n) + h(n)`
