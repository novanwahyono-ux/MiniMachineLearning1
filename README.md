# MiniMachineLearning

A machine learning and algorithm engineering workspace focused on implementing, studying, and experimenting with fundamental AI and computational algorithms using Python.

This repository serves as a growing collection of:

* search algorithms
* graph traversal techniques
* machine learning fundamentals
* natural language processing experiments
* optimization approaches
* heuristic-based problem solving

The primary goal of this project is to strengthen understanding of algorithmic thinking, artificial intelligence fundamentals, and practical engineering implementation.
